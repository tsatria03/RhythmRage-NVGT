New in 1.4.
Fixed levels with similar names sometimes showing each other's rating in the level select. In some cases, improving your score on one of them could also erase the other's saved result.
Pressing tab in the level select now also tells you your pack mastery. This is a single percentage covering your best score on every level, and it starts once you have completed a level.
The level select now announces your best score percentage on each level you have played, right before its rating.
After finishing a level, you can now press enter during the score calculation to skip the suspense and jump straight to your result.
Pressing escape during a perfect run or a level's soundtrack now opens a pause menu with resume and quit, instead of leaving straight away.
Pack creators can now test a pack straight from its source files, with every level unlocked and nothing saved. Testing never touches your installed packs.
If you have no packs at all, the game now sets up the default packs when it starts. It builds them from files included with the game, and only downloads them if those files are missing.
New in 1.3.
Pack creators can now compile a pack from its source files, or decompile one back into editable source, from the main menu.
The pack downloader now returns you to the list after each download, so you can grab several packs in a row without reopening it.
Your packs are now kept in a folder in your app data.
In the main menu, you can now press tab to hear which pack you are currently playing.
The music that plays after you finish a level can now be turned up or down with page up and page down.
In the level select, pressing tab now tells you how many of the pack's levels you have completed.
Pressing escape in the main menu now asks you to confirm before quitting. The exit menu item still quits right away.
Pressing escape during a level or tutorial now opens a pause menu instead of leaving straight away. From there you can resume, quit to the level select, restart a level, or skip a tutorial. Pressing q while reading a tutorial also skips it.
The level select now reopens on the level you were last on, even after restarting the game.
Every menu now shares one remembered music volume, so it no longer resets when you open the level select.
New in 1.2.
While playing a level, you can now raise or lower its background music with the page up and page down keys.
You can now restart the game from the main menu.
The pack downloader no longer lists packs you have already downloaded.
While a pack downloads, its progress is now played as a rising beep instead of a spoken percentage.
Packs are now kept in a data folder next to the game, so all your content stays together and travels with the game folder.
The pack downloader works again, and now downloads new packs from a new server.
Pressing escape to leave a level now stops any sounds that were still playing, instead of letting them finish after you have left.
Fixed the Rhythm and Spell level in the Retro pack, where the letters were silent and the level failed with an error.
The game now remembers which pack you were playing and reopens it when you restart, instead of always going back to the default pack.
Your saved game is now kept in a data folder right next to the game, so you can move the whole game folder to another computer and keep your progress.
New in 1.1.
The main menu music volume is now remembered between sessions.
Your keyboard delay setting is now saved, so you no longer have to recalibrate it every time you start the game.
The game now stops you from opening more than one copy at the same time. This also applies to the level tool program.
You can now switch the game's language between English and Spanish from the main menu, and your choice is remembered.
In the store and change pack menus, the tab key is now used to hear your credits. This moved off the m key so letters can jump to packs by name.
In a menu, you can now press a letter to jump to the next item that starts with it.
Menus can now be navigated with the left and right arrow keys as well as up and down.
When testing a pack, pressing escape now returns to the level select screen instead of closing the game.
You can now cancel a pack download with escape, and downloading a pack no longer freezes the game.
Fixed interactive tutorials, which were not registering any key presses at all.
New in 1.0.
Locked levels in the level select menu now announce their name and locked status the same way unlocked levels announce your progress.
Your saved progress is now stored in your app data folder, under Oriol Gomez, rg, saves.
The store now charges 1000 credits per pack, and you need at least that much to shop.
Fixed a scoring problem where releasing a tap and hold note slightly late could still count as a good release instead of a mistake.
The level tool now lists all the pack folders in your mypacks folder and lets you pick which one to work on. To test a level from a pack, copy that pack into the packs folder first.
Added a level tool for pack creators, a separate program that plays a sound file and helps you find the exact millisecond positions and BPM marks you need when timing a level's sounds and actions.
Fixed loose pack testing: dropping a pack folder into the packs folder again builds it and loads you straight into it in creator/test mode with all levels unlocked, without saving progress or achievements to your profile, and rebuilds it every launch so your edits show up right away.
Converted the entire game to NVGT.
Added keys abcdefghijklmnopqrstuvwxyz1234567890 for actions!
The q key doesn't quit anymore because its a possible action, instead you should use escape now.
The reaction time can now be modified from within the level by saying misc reaction=value. default is 150, 75 too early and 75 late.
Changed some of the levels to make it easier.
You can now configure keyboard delay!
Fixed a bug when saving data.
Added a bunch of fixes for debug mode.
Added page up and page down as music volume keys for menus.
Added a fail= for requires.
You can now listen to a perfecct run of a level.
Change tutorial question for tutorial/play/run menu.
Fixed very important file saving bug.
