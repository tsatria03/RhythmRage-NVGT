RhythmRage-NVGT is a port of Oriol Gomez's audio-only rhythm game from BGT (Blastbay Game Toolkit) to the new NVGT ([[nvgt-engine-location]]).

**Original BGT source (reference for the port):** `C:\Users\tonys\OneDrive\Desktop\rhythm-rage bgt-src` (path confirmed 2026-09-14; was previously `Rhythm_rage BGT_src`). Contains `game.bgt`, `classes.bgt`, `leveltool.bgt`, and the original `include/` files — use it to compare behavior when porting or diagnosing divergences from the original. NVGT differs substantially from BGT, so a divergence isn't automatically a port bug.

**Loose-pack testing behavior (important, non-obvious):**
- `main()` must call `generate_packs()` (the BGT-faithful single-folder builder), NOT `generate_all_packs()`. The port originally used `generate_all_packs()`, which compiled a loose folder to a `.pack` but did NOT load you into it and skipped rebuilds once the `.pack` existed. `generate_all_packs()` has been removed as dead code.
- A loose pack = a folder of raw `.ogg`/`.lvl` files dropped directly into the app-data packs folder `packdir` (`%APPDATA%\Oriol Gomez\RhythmRage\packs\`). On launch `generate_packs()` builds `packdir/<name>.pack`, sets `pack` to it and `creatingpack=true`, then `main()` opens it and runs in creator/test mode: all levels unlocked, rebuilt every launch so edits show up. Only ONE loose folder allowed at a time (else "Multiple packs" alert). This BGT-style flow still works, but the usual way now is the main menu's **test a pack** item (below).
- **Why testing doesn't corrupt your profile:** `ser()` (the only function that writes `save/rg.dat`) early-returns when `creatingpack` is true, so achievements, unlocks, and credits earned while testing a loose pack are never saved. This was true in BGT and is preserved here.
- **`mypacks/` (`path+"mypacks/"`) IS read by the game now** (it wasn't in BGT). The main menu's **test a pack** item builds a source folder to a throwaway `DIRECTORY_TEMP/temptestNNNNNN.pack` and runs it in creator mode (`testing=true`; escaping the level select ends the test and restores the previous pack). **Compile a pack** builds a source into `packdir`, and **decompile a pack** unpacks one back into `mypacks/`. On a first run with no packs, `ensure_default_packs()` compiles `default`/`default_espanol` from `mypacks/`, or downloads them. The separate `lt.nvgt` level tool also scans `mypacks/` for its pack picker.

**Layout (git repo, remote https://github.com/tsatria03/RhythmRage-NVGT.git):** source lives in **`src/`** (`rg.nvgt`, `lt.nvgt`, `lt.properties`, `includes/`), game data/run files in **`rg/`** — runtime data under **`rg/data/`** (`assets/` = `sounds1.pack`/`sounds2.pack`, `saves/` = `rg.dat` plus `.tmp`/`.bak`; rhythm packs are NOT here, they're in app data), plus `mypacks/`, `sounds/` (raw source), `docks/` (`english/`+`spanish/`), launchers. `rg.nvgt`'s `#include "includes/..."` lines resolve because they're relative to the script (src/). `bgt_compat.nvgt`/`sound_pool.nvgt` stay bare (engine include path). Changelog: `docks/english/changelog.txt`. Full run/build details → [[rhythm-rage-run-and-build]].

**Sound packs, rhythm packs & save location:** built voice/UI sound packs `sounds1.pack`/`sounds2.pack` live in **`rg/data/assets/`**. Compiled rhythm packs (and any loose author folder for creator mode) live in the fixed app-data **`packdir`** = `DIRECTORY_APPDATA+"/Oriol Gomez/RhythmRage/packs/"`, created in `main()` and the same for source, portable, and installed runs. `set_sound_storage`/`package.create`/`generate_soundpack()` use `path+"data/assets/sounds"+lang+".pack"`; `generate_soundpack()` scans the raw source `path+"sounds/*"` (`rg/sounds/`). Pack loading goes through `cur_pack_file()` (`packdir+pack+".pack"`, or the temp test build while `testing`). See `nopack()`/`yespack()` in `includes/utils.nvgt`. The save `rg.dat` is now **portable**: `path+"data/saves/rg.dat"` (moves with the game folder — `path` is `../rg/` from source, `""` compiled, `%APPDATA%/Oriol Gomez/rg/` when installed), created via `directory_create(path+"data/saves")` in `main()`; `ser()` still early-returns while `creatingpack`. `.gitignore` excludes the built binaries (`rg/data/assets/`, `rg/mypacks/`, `rg/lib/`), the dev's `rg/data/saves/rg.dat` (plus `.tmp`/`.bak`), the generated `rg/pack_index.txt`, `releases/`, and the intermediate build bundles (`src/rg/`, `src/rg.app/`). Raw `rg/sounds/` source IS tracked.
